# 🌊DIVE2024 해커톤 - Donghae.zip

DIVE2024 해커톤의 여러 발제사 중 코레일을 선택하여 코레일에서 지정해준 주제인 "사람들에게 동해선을 홍보할 수 있는 서비스" 에 대한 프로젝트를 진행했습니다.
Donghae.zip은 사람들에게 동해선 여행플래너 기능 및 정보 제공을 해주는 서비스 입니다.

## 🗓️개발 기간

- 시작일: 2024.09.20
- 종료일: 2024.10.06 ~ing

## 👨‍💻개발자 소개 및 역할 분담

저희는 서경대학교 소프트웨어학과 학생으로, 부산에서 열리는 DIVE2024 해커톤에 "IT서경꿈나무들" 팀으로 참가하였습니다.

- 👶**김영재**
- 👦**이은학**
- 🧑‍🦰**류승환**

## 💻개발 환경

- 운영 체제: Windows 11, macOS
- IDE: IntelliJ IDEA
- 기타 도구: Postman, Swaager

- 언어:

    - Java (Spring Boot)

- 프론트엔드:
    - CSS
    - JavaScript
    - React
- 백앤드

    - 기상청 API (날씨 정보 제공)
    - 카카오 지도 API (지도 기능)

## 📌프로젝트 상세내용 및 기능 설명

1. **사용자 인증 :**
    - JWT 기반 이메일 로그인/로그아웃 및 회원가입 기능을 구현했습니다.
    - 소셜 로그인 기능을 추가해 다양한 사용자 접근성을 제공했습니다.

2. **관광지, 숙소, 식당, 축제, 둘레길 데이터 페이지 :**
    - 저희는 코레일에서 제공해 준 데이터와 Python의 BeautifulSoup, Selenium을 사용하여 크롤링한 동해선 역 주변 관광지, 숙박, 식당, 축제, 둘레길 데이터를 각각의 페이지에 분류하여 페이지 별로 보여주는 UI를 구성하였습니다.
    - 페이징 처리를 통해 많은 데이터를 효율적으로 조회할 수 있도록 했고, 태그 및 검색어 필터링 기능을 추가해 원하는 정보를 쉽게 찾을 수 있도록 했습니다.
    - 각 요소를 클릭하면 상세보기 페이지로 이동하여 사용자가 세부 정부를 볼 수 있고, 리뷰를 남길 수 있도록 하였습니다.

3. **역 정보 데이터 페이지 :**
    - 사용자들이 역 정보 페이지에 들어가면 동해선 노선도가 나오고, 코레일에서 제공해 준 각 역의 편의시설 데이터, 운행 시간 데이터 등의 역 정보 데이터를 활용하여 사용자들이 노선도에 마우스를 올리면 해당 역의 정보가 나오도록 구현하였습니다.

4. **메인 페이지의 동해선 승하차객 데이터 시각화 :**
    - 코레일에서 제공한 시간대별 동해선 역별 승하차객 수 데이터를 시각화하여, 메인 페이지에서 파이 차트를 통해 쉽게 확인할 수 있도록 했습니다.

5. **메인 페이지의 동해선 근처 관광지, 숙소, 식당 보여주기 :**
    - 카카오 지도 API를 이용하여 동해선 역을 지도 상에 표시하였고, 각 역을 클릭 시 역 주변 반경 1km, 1.5km, 2km, 3km 내에 있는 관광지, 숙박, 식당 정보를 보여주는 기능을 구현했습니다.
